# Alua B. — Hybrid Portfolio

Responsive portfolio built with HTML, CSS, and JavaScript. It brings together business and analytics, marketing and digital, psychology and research, and visual design.

## Files
- `index.html` — content
- `style.css` — design and responsive layout
- `script.js` — automatic footer year
- `assets/` — resume PDF and optional images

## Before publishing
- Replace `YOUR_EMAIL@example.com` with your email.
- Replace `YOUR-LINKEDIN` with your LinkedIn profile slug.
- Add your resume PDF to `assets/` and name it `Alua-B-Resume.pdf`.
- Review titles, dates, project descriptions, and ensure you have permission to share any client/employer work. Use anonymized or recreated data where needed.

## Preview
Open `index.html` in your browser, or use VS Code with Live Server.

## GitHub Pages
1. Create a public repository named `alua-bllv.github.io`.
2. Upload the contents of this folder to the repository root.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Website: https://alua-bllv.github.io
